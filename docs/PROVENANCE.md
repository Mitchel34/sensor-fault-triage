# Provenance

The detector, generator, matcher, CLI, receipt exporter, wheel builder and behavior tests were authored for this project. The synthetic formula, noise levels, fixed seeds and injection intervals were chosen as toy examples before fitting any baseline or executing the evaluation. They are documented in the frozen protocol. No private industrial observations, parameters, external datasets, prior project implementation or research results were used.

The authorized generic publication checklist was consulted during preparation and removed from the final deliverable. No template cache, history, private coordinator implementation or metadata was copied into the final tree. The project uses the Python standard library and includes no vendored third-party code, license declaration or hosted workflow.

Test receipt examples are invented schema fixtures expressly marked as such. They verify failure reporting and do not represent sensor measurements. The small demo is a separately labelled handcrafted input. Only a genuine admitted evaluation receipt may supply published performance measurements.
